How it works

Supported: hosted boards (jobs.lever.co/acme, boards.greenhouse.io/acme, acme.wd5.myworkdayjobs.com/…), embedded boards and custom-domain career sites that run one of the supported platforms.

We only index sites whose robots.txt allows it, with a clear User-Agent and at most one request per second per site. Requests are reviewed before indexing. Developers: POST /sources (API docs).
