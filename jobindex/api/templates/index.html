Use JobForge in your AI agent

JobForge is also an MCP server, so an AI agent can search this index for you. It offers two tools, search_jobs (query, company, location, workplace, page) and get_job (full description and apply links). It is read-only, needs no account and is rate-limited per client.

Claude Code

claude mcp add --transport http jobforge {{ mcp_url }}

Claude Desktop

Settings → Connectors → Add custom connector, URL {{ mcp_url }}. Or in claude_desktop_config.json:

{
  "mcpServers": {
    "jobforge": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ mcp_url }}"]
    }
  }
}

Other MCP clients: Streamable HTTP transport, endpoint {{ mcp_url }}.
